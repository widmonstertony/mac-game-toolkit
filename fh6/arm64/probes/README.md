# FH6 ARM64 integration probes

These probes use a temporary Wine prefix and leave the installed launcher, game, and bottle configuration alone. They do not start a game.

- Run `bash verify.sh metal` with `VULKAN_INCLUDE` set to the Vulkan-Headers include directory, `FFX_SDK_ROOT` set to the FidelityFX SDK's `Kits/FidelityFX` directory, and `DEVELOPER_DIR` set to the Xcode installation with the Metal compiler. The script builds the existing fsr4-native-macos source for ARM64. It allocates exportable KosmicKrisp images, converts a FidelityFX dispatch descriptor to a Metal frame, and verifies the FSR 4.1.2 pixels from a Vulkan readback at 3472 × 2266. The last readback submission waits on a Vulkan timeline value released by the Metal completion callback.
- Run `bash verify.sh d3d12` with the same SDK settings, plus `LLVM_MINGW_BIN`, `WINE_SOURCE`, `WINE_BUILD`, `VKD3D_INCLUDE`, `VKD3D_GENERATED_INCLUDE`, and `FFX_FRAMEGEN_DLL`. Use the patched Highball r4 Wine 11.18 source and its configured build directory. Set `FFX_FRAMEGEN_DLL` to the installed AMD D3D12 frame generation library. A Windows FEX process produces color, depth, and motion textures through D3D12. A same-process Wine Unix library resolves their KosmicKrisp heaps and encodes native FSR 4.1.2 on Metal. The AMD frame generation dispatch consumes that 3472 × 2266 image on a D3D12 command list waiting on Metal completion. The probe reads both outputs back and checks that both generated frames put the moving shape halfway between its positions in adjacent source frames.
- Run `bash verify.sh steam` with `LLVM_MINGW_BIN` set to the llvm-mingw bin directory and the native Steam client signed in. The probe loads a Windows Steam API forwarder and opens a pipe to the existing macOS Steam session through Proton-ish. It also verifies SteamClient021 interface calls on the main thread, on a worker, and back on the main thread using the same client pipe. It does not launch Windows Steam.

Highball r4's installed VKD3D provides `GetVulkanResourceInfo1`, `BeginVkCommandBufferInterop`, and `GetVulkanHeapInfo`. A separate FEX/D3D12 check resolved RGBA16F, D32F, and RG16F images. Exporting the D3D12 heap itself through `CreateSharedHandle` returned `E_NOTIMPL`. The Vulkan allocation in the Metal probe is created explicitly as exportable, so that result does not establish that arbitrary D3D12 textures are directly shareable.

The D3D12 probe controls the staging texture descriptors and owns the producer and consumer command lists. It does not exercise the game's recording sequence or swapchain presentation. The game path needs a submission boundary at the FidelityFX dispatch, compatible staging textures for the game resources, and resource lifetime tracking through frame generation. The Steam probe verifies IPC and an existing login. App-specific startup, Steam Cloud, and online gameplay still require game validation.
